STEP 01 / COMPARE

先找到真正的变化

忽略对象键顺序，数组按索引比较。每条变化都有 JSON Pointer。

单份 ≤ 1 MiB · 深度 ≤ 80

例如 /a~1b 表示键 a/b；~ 转义为 ~0。预览不改动原输入；不存在的路径会报错，不会假装已脱敏。

格式化与压缩使用上方左侧 JSON，也会执行严格校验。

URL 使用 encodeURIComponent/decodeURIComponent，仅处理组件，+ 不视为空格。日期输入时区显式选择；时间戳结果同时显示北京时间及 UTC。

准备就绪。内容不上传、不写入 URL 或浏览器存储。

处理结果

脱敏是辅助工具，不是安全保证。请检查预览中是否仍含其他敏感字段、数组元素或自由文本；确认后再复制、下载或分享。

01 / SEMANTIC DIFF

只看有意义的变化

对象键顺序不同不算差异；数组按索引，不做智能匹配。新增、删除、修改分别标记，根路径显示为空字符串。最多展示 2,000 条差异，超出明确提示。

02 / SAFE PREVIEW

先保护数据，再交接

路径脱敏输出独立副本，不覆盖原始输入。重复键与不安全大整数会阻止处理；请把大整数作为字符串传入。小数仍使用 IEEE-754，非任意精度。

03 / SAMPLE TO TYPES

类型起点，而非契约

仅由当前单份样例推断 TypeScript；不推断可选字段、完整联合分支、日期格式或业务约束。生成结果必须人工审阅，不是 API schema。
